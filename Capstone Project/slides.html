Data Processing Pipeline

Pipeline Overview:

  1. Load and clean raw data (CSV, JSONL)

Machine Learning Pipeline — Part 1

Text Processing & Targets:

  1. Text preprocessing:
    • Clean and tokenize reviews
    • Build TF-IDF features (cached in artifacts/tfidf.pkl)
  2. Target preparation:
    • Star ratings for regression
    • Sentiment classes for classification

Machine Learning Pipeline — Part 2

Model Training:

  1. Data splitting and preprocessing pipelines
  2. Handle class imbalance: SMOTE, undersampling, class weights
  3. Train multiple models (LogReg, RF, GB, ensembles)
  4. Evaluate with classification reports and confusion matrices
